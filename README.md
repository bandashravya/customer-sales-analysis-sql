# Customer Sales Analysis Using SQL

## Project Overview

This project analyzes customer and sales data using MySQL. It helps understand customer purchases, revenue, profit, and product performance.

## Tools Used

* MySQL
* SQL
* GitHub

## Database Tables

* **Customers:** Customer ID, Name, City, Street
* **Orders:** Order ID, Customer ID, Order Date, Product, Units, Revenue, Profit

## SQL Concepts Used

* CREATE TABLE
* INSERT INTO
* SELECT
* INNER JOIN
* LEFT JOIN
* GROUP BY
* ORDER BY
* Aggregate functions such as SUM and AVG

## Business Questions

1. What are the details of each customer's orders?
2. Which customers generate the highest revenue?
3. Which city generates the highest sales?
4. Which products sell the most?
5. Which customers have not placed any orders?
6. What is the monthly revenue?

## Project Goal

To practice SQL queries and learn how businesses can use sales data to make better decisions.

## Dataset

Sample customer and sales data will be included in this repository for learning purposes.
## SQL Concepts Used

* CREATE DATABASE and CREATE TABLE
* INSERT INTO
* INNER JOIN and LEFT JOIN
* GROUP BY and ORDER BY
* Aggregate functions: SUM(), COUNT(), AVG()
* Date functions for monthly sales analysis

## Analysis Performed

* Combined customer and order details using INNER JOIN
* Calculated total revenue and profit by customer
* Compared revenue across cities
* Identified best-selling products
* Checked customers without orders using LEFT JOIN
* Analyzed monthly revenue and profit
* Calculated average order value

## Project Files

* `customer_sales_analysis.sql` — Database and table creation
* `insert_sample_data.sql` — Sample customer records
* `insert_orders.sql` — Sample order records
* `analysis_queries.sql` — SQL analysis queries

## How to Run

1. Open MySQL Workbench.
2. Execute `customer_sales_analysis.sql`.
3. Execute `insert_sample_data.sql`.
4. Execute `insert_orders.sql`.
5. Execute the queries in `analysis_queries.sql`.
